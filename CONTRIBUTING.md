# Contributing to Kesh Atelier

Thanks for helping improve this project. Bug fixes, design improvements, accessibility fixes and new features are all welcome.

## How to contribute
1. Fork the repository and create a branch for your change.
2. Keep changes focused: one fix or feature per pull request.
3. Test the page locally (open `index.html`, or run `npx vercel dev` to try the booking API).
4. Open a pull request that explains what you changed and why.
